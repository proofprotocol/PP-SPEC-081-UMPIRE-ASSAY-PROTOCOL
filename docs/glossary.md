# Glossary

*Informative. Definitions in [SPEC.md](../SPEC.md) Section 2 control.*

| Term | Meaning |
|---|---|
| Reproof | Independent re-execution of a proof, compared to the original under limits fixed in advance |
| Head Assay | The original run, Engagement, or Bundle being reproven |
| Check Assay | The independent re-execution |
| Umpire Assay | The third, beacon-drawn execution that settles a divergence |
| Repeat Run | A re-execution sharing any party or affiliate with the original; never reproof |
| Party Set | Every party occupying a seam of an Assay, with its Affiliates |
| Affiliate | A party linked by control, employment, equity, shared keys or staff, or a recent paid relationship concerning the same DUT or Provider |
| Split | What is held constant: control, environment or class, test shape, claims, coverage. Never the canaries |
| Splitting Limit | The declared maximum difference within which two Assays agree |
| Cell | One Compared Metric in one stratum, such as Stopped rate for one technique class |
| Insufficient | Not enough Units of Proof, or too much Blind or Void, to compare. Neither agreement nor divergence |
| Instance Reproof | Check against the same deployed SUT |
| Class Reproof | Check against a different SUT in the same Comparability Class |
| Reproof Manifest | The anchored declaration published before the Check Assay commits |
| Comparison Record | The mechanical, Cell-by-Cell result |
| Divergence Finding | A Cell outside the Splitting Limit, with its direction |
| Confirmed Claim Finding | A Provider claim missed in both Assays |
| Reproof Status | Computed from the Registry: single, pending, checked_insufficient, reproven, divergent, not_upheld, disputed |
