## Rules

1. **Credit, not authorship.** An acknowledgement records an influence or a contribution of an idea. It does not make the person an author, an inventor, a reviewer, or an endorser of this work, and it does not change Section I (Original Inventor) of the license.
2. **Accurate origin.** Every material idea, name, or prior work drawn from another person is acknowledged here, as the Proof Economy Code of Ethics requires (Section 8.7). Nothing is removed from this file to minimize a contribution.
3. **Markers.** Each acknowledgement is one `[ACKNOWLEDGED]` ... `[/END OF ACKNOWLEDGED]` block with `Name:`, `Contribution:`, and `Applies to:` lines, so a person and a program read the same list. A file with no blocks acknowledges no one.
4. **History.** This file is versioned with the repository. An acknowledgement, once made for a version, stays in that version's history.
